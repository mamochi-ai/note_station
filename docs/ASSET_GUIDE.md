# 素材ガイド

decor_atlas.pngは透明背景の水彩装飾6点。左上から樹木、街並み、橋、駅舎、雲と鳥、小さな列車。atlas.jsonの矩形は元画像のピクセル座標です。
画像生成による装飾素材であり、路線・駅・文字のデータ表現には使いません。路線図自体はSVGで描画してください。
個別PNGではなくシート形式。描画時の切り出し、または開発時に各矩形で切り出して使ってください。元画像の透明度を保持し、白背景に焼き込まないこと。
空き領域にopacity 0.15〜0.35程度で配置する目安。駅舎や列車を主役にする場合のみ濃くしてよい。クリック判定を持たせない。
UI_SYMBOLS.svgはコード製の単純な記号集。station / interchange / planned / routeのsymbolを参照できる。文字・路線色・接続はアプリ側で決める。
画像の装飾は分類結果や記事数の意味を持たない。駅ごとの挿絵は必須ではありません。

## 制作
PNGは内蔵画像生成ツールで制作。指示要旨：淡いセージ・砂色・青の日本の旅行誌風水彩。樹木、街、橋、駅、雲、列車の6点を透明背景に独立配置。文字とUIは含めない。
